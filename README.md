# Yishan Xing — Robotics Portfolio

A responsive personal portfolio for MSc Robotics / CPD coursework. Static HTML, CSS and JavaScript, suitable for free GitHub Pages hosting; no build system required.

## Preview locally

Open `index.html` in a browser. The main page and `cv.html` work offline (Google Fonts may fall back to standard fonts).

## Publish using GitHub Pages

1. Log in to GitHub as **Yishan-Xing**.
2. Create a **public repository** named `Yishan-Xing.github.io`, if it does not exist already.
3. Upload the **contents of this folder**, not the ZIP as one file. Keep `index.html`, `styles.css`, `script.js`, `cv.html`, `Yishan_Xing_CV.docx` and the `assets/` directory in the repository root.
4. In repository **Settings → Pages**, select **Deploy from a branch → main / (root)**, then save.
5. Once published, the site URL should be `https://Yishan-Xing.github.io/`.

## Site contents

- `index.html`: all main sections: introduction, projects, skills, education, research, contact
- `styles.css`: responsive layout and colours
- `script.js`: mobile navigation and dynamic footer year
- `cv.html`: readable online CV and print option
- `Yishan_Xing_CV.docx`: Word CV based on the user-provided document
- `assets/yishan-xing-portrait.jpg`: personal portrait (used **once** in the website)
- `assets/semg-gesture.png`, `pet-robot.png`, `cap-glioma.png`, `seal-inspection.png`: project images provided by Yishan Xing
- `assets/project-rover.svg`: existing Leo Rover illustration, unchanged

## Before submitting

- Verify the full manuscript title, author order and current submission status with the supervisor. The title is provisional.
- Check the wording and links, particularly external repositories.
- For the CPD coursework, submit the *published URL*, not the ZIP. Leave the site live for at least three weeks after submitting, and avoid editing it after the coursework deadline.
- Project imagery and personal photo are owner supplied; Leo Rover graphic is an illustration. Confirm the rights to publish any project images, especially if collaborators or third parties own them.
